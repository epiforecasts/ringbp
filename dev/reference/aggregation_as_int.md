# Number of days in an aggregation time interval

Number of days in an aggregation time interval

## Usage

``` r
aggregation_as_int(aggregation)
```

## Arguments

- aggregation:

  a time interval, standardised by
  [`match_aggregation()`](https://epiforecasts.io/ringbp/dev/reference/match_aggregation.md).
  `"none"` is measured in days.

## Value

An `integer` scalar.
